# example_architectures/

Placeholder for `.arch` files released from example-designs between
coredla releases (out-of-cycle).  Contents land in
`$COREDLA_ROOT/example_architectures/` after install, alongside the
archs coredla ships at build time.  Anything added here is folded into
coredla's `example_architectures/` at the next coredla release, so the
two sets are back in sync on-cycle.
