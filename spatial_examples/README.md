# Spatial examples

For handcrafted models, see `lstm_addition`, `magika`, `mnist_mlp`,
`sequential`, and `tiny_story`.

For compiler examples, see `autoencoder`, `gptneo`, `magika`, `qwen`, and
`resnet8`.

Run each example from its own directory and follow its README for model setup,
dependencies, and command-line options.

All models are supported on Agilex 7 OFS ED.

Models supported on Agilex 5 JTAG ED:
Resnet8
Magika - only magika_spatial_small.py
